# ELF Arsenal

[[Pages and Workflows]] · [[Manage Jailbreak]] · [[Settings Reference]]

ELF Arsenal is the dedicated ELF catalog and asset-management page.

## What it does

- Presents available ELF entries from configured sources.
- Retrieves/downloads selected ELF assets to local storage.
- Organizes local entries for later use in a user-authorized console workflow.
- Integrates with configured notifications and related payload-management settings where supported.

## Before using it

Review the asset source, title, version, checksum/provenance where available, and intended console compatibility. Configure any local storage destination before downloading.

## Caution

An ELF catalog is not a compatibility guarantee. Do not treat a download as safe to run solely because it is listed. Confirm firmware, payload loader, source trust, and recovery path independently.
