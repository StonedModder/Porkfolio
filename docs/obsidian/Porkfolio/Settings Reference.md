# Settings Reference

[[Pages and Workflows]] · [[Dashboard]] · [[Platform Support]]

Settings controls Porkfolio's connection details, local paths, feature behavior, and interface preferences. Configure it before performing PS5-connected operations.

## FTP Connection

- Host/IP address, ordered port list, username, password, and optional reconnect behavior.
- The port list lets Porkfolio try the configured ports in sequence.
- Use the connection test from [[Dashboard]] after saving changes.

## Game and storage paths

- **Game Source Folders:** local backup roots used by [[Backups]].
- **Backpork Folders:** local firmware-labelled patch roots used by [[Backporks]].
- **Remote Game Paths:** PS5 locations scanned and used by [[Games]] management workflows.
- **Payload paths:** local and remote directories used by [[Manage Jailbreak]].

## Media and sharing

- Local download directory used by [[Media]].
- Optional Discord/webhook delivery settings and per-step notification behavior.
- Keep webhook values private.

## Console feature settings

- Remote cheat path for [[Cheats]].
- PS Notify host, port, and timeout for [[PS Notify]].
- Voidshell/service port where that embedded page requires it.
- Save and Garlic-related companion configuration where supported.

## Conversion settings

- Conversion mode, output/temp folders, queue behavior, auto-upload, and cleanup settings.
- UFS2/FFPKG and ExFAT fields apply to Windows-only tooling; see [[Platform Support]].

## System View and appearance

- Capture-device preferences, resolution, recording/hotkey behavior, popout/fullscreen choices, and optional auto-load for [[System View]].
- Accent color, time display, and available language selection.

## Safe configuration practice

Save only data you are comfortable storing locally on the computer. Do not commit app data, exported configuration, logs, databases, save keys, passwords, webhook URLs, or tokens.
