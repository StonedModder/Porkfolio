# Backups

[[Pages and Workflows]] · [[Games]] · [[Transfers]] · [[Settings Reference]]

Backups manages local game-backup folders stored on the computer running Porkfolio.

## What it does

- Scans configured local source roots for recognizable game folders.
- Calculates and displays local backup size and status.
- Associates local folders with entries in [[Games]].
- Supports file/folder hash operations and comparison with available local community-hash data.
- Provides a starting point for upload/download and restore-oriented workflows.

## Setup

Add one or more source roots in **Settings → Game Source Folders**, then run a backup scan. Use paths that contain only the folders you want Porkfolio to inventory.

## Safety

Hash verification is useful evidence, not a substitute for checking source provenance, completeness, or compatibility. Never make a destructive change to the only copy of a backup.
