# Cheats

[[Pages and Workflows]] · [[Games]] · [[Transfers]] · [[Settings Reference]]

Cheats manages compatible cheat-collection files for games in the Porkfolio library.

## What it does

- Fetches and indexes configured cheat-source metadata.
- Searches cheat files by game title or ID.
- Downloads selected files to local storage.
- Installs selected cheat files to the configured remote cheat location through FTP.
- Highlights unmatched files that do not currently map to a game in the local database.

## Setup

Configure the remote cheat location in [[Settings Reference]] and connect to the PS5 FTP service before installation.

## Caution

Cheat file availability does not establish compatibility with a particular title version or payload. Confirm the target title/game ID and retain a backup of any existing remote cheat configuration before replacing it.
