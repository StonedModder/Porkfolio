# xAvatar Management

[[Pages and Workflows]] · [[Transfers]] · [[Settings Reference]]

xAvatar Management creates and handles PS5 `.xavatar` files from images.

## What it does

- Accepts supported image input through file selection, drag-and-drop, or clipboard workflows.
- Generates avatar variants and metadata required by the xAvatar format.
- Previews a generated avatar before saving.
- Saves `.xavatar` output locally.
- Uploads a generated avatar to a configured PS5 location through FTP.
- Extracts a PNG preview from an existing `.xavatar` where supported.
- Lists compatible avatar files available on the configured console path.

## Before using it

Connect to FTP for console upload/browse actions. Use a copy of source artwork and confirm the remote avatar directory before upload.

## Caution

The page produces/uses a console-specific format; successful local conversion does not guarantee that every console environment or avatar consumer will accept the file. Preserve known-good avatars before replacement.
