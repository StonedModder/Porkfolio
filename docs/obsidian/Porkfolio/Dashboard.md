# Dashboard

[[Pages and Workflows]] · [[Settings Reference]] · [[Games]] · [[Transfers]]

The Dashboard is the operational start page. It summarizes the local Porkfolio database and provides the fastest route to connect to a configured PS5 FTP service.

## What it shows

- Total known games, installed games, backed-up games, and backup counts.
- Current FTP connection state.
- Recent activity from Porkfolio operations.
- User-selected pinned cards and widgets.

## What you can do

- Enter or reuse FTP host and port settings for a quick connection attempt.
- Connect or disconnect from the console.
- Start a scan once connected.
- Pin supported feature cards for a focused workflow.
- Navigate to a relevant page from a pinned card or status item.

## Before using it

Configure the FTP host, ports, credentials, and remote paths in [[Settings Reference]]. A connection only proves that the configured FTP endpoint answered; it does not validate every later path or payload-specific feature.
