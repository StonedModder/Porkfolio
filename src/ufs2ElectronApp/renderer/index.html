About

UFS2 Patcher applies backpork patches to PS5 game folders and converts them to a backup image.

Workflow (both modes):
1. Copy game directory → temp worker folder
2. Overlay backpork patch files onto the copy
3a. FFPKG mode: Run UFS2Tool makefs (or newfs) → .ffpkg image
3b. ExFAT mode: Run make_image.bat (OSFMount) → .exfat image
4. Clean up the temp worker directory

ExFAT mode requirements:
• OSFMount must be installed
• make_image.bat and New-OsfExfatImage.ps1 must be in the same folder
• The game source folder must contain eboot.bin at its root
• Image is auto-sized to fit content; source is formatted & copied into image root

Both modes require Administrator elevation. Run this app as Administrator.
